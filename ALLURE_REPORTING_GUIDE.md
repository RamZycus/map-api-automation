# Allure Reporting Guide

## Overview
This project is configured to automatically generate Allure JSON results after every test execution. Users can then generate and view beautiful HTML reports using Allure.

## How It Works

### 1. Automatic JSON Generation
Every time you run a test, Allure JSON results are automatically generated in the `allure-results/` directory.

### 2. Available Commands

#### Run Tests (generates Allure JSON automatically)
```bash
# Run specific test with tag
$env:SETUP="QC";$env:TENANT="ZCS";npm run test:tag "@completeWorkflow"

# Run complete workflow test
$env:SETUP="QC";$env:TENANT="ZCS";npm run test:completeWorkflow

# Run any other test
$env:SETUP="QC";$env:TENANT="ZCS";npm run test:tag "@createFlow"
```

#### Generate and View Allure Reports
```bash
# Generate HTML report from JSON results
npm run allure:generate

# Open generated report in browser
npm run allure:open

# Serve report directly (recommended)
npm run allure:serve
```

## Complete Workflow Example

1. **Run your test:**
   ```bash
   $env:SETUP="QC";$env:TENANT="ZCS";npm run test:completeWorkflow
   ```

2. **View the report:**
   ```bash
   npm run allure:serve
   ```

3. **Open browser** to the URL shown in terminal (usually `http://localhost:port`)

## What You'll See in Allure Report

- **Test Overview**: Summary of passed/failed tests
- **Test Details**: Step-by-step execution details
- **API Requests/Responses**: Complete request and response data
- **Timeline**: Execution timeline with duration
- **Environment Info**: Test environment details
- **Attachments**: JSON dumps and other files

## Directory Structure

```
├── allure-results/          # JSON results (auto-generated)
├── allure-report/           # HTML report (generated by allure:generate)
├── test-results/            # Other test results
└── jsonDumpRepository/      # API execution dumps
```

## Tips

- **Always use `allure:serve`** - it's the most convenient way to view reports
- **JSON results persist** - you can generate reports anytime after test execution
- **Multiple test runs** - Allure aggregates results from multiple test executions
- **Clean reports** - Use `allure:generate` with `--clean` flag to get fresh reports

## Troubleshooting

If Allure reports don't show up:
1. Check if `allure-results/` directory has JSON files
2. Ensure `allure-commandline` package is installed
3. Try running `npm run allure:generate` first, then `npm run allure:serve`
